# CLI Interface Contract

**Feature**: 009-cli-configuration
**Date**: 2026-04-11

## Usage

```
blockchain [OPTIONS] <blockchain-directory>
```

## Positional Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `<blockchain-directory>` | Yes | Path to the blockchain data directory. Must exist on disk. |

## Options

| Flag | Short | Argument | Default | Description |
|------|-------|----------|---------|-------------|
| `--help` | `-h` | none | — | Print usage information and exit |
| `--version` | `-v` | none | — | Print program name and version, then exit |
| `--config` | | `<path>` | `<blockchain-directory>/config.json` | Path to configuration file |
| `--rpc-port` | | `<port>` | 12345 | Override RPC listen port (1–65535) |
| `--p2p-port` | | `<port>` | 12346 | Override P2P listen port (1–65535) |
| `--seed-node` | | `<host:port>` | (none) | Add a seed node (repeatable) |
| `--log-level` | | `<level>` | `info` | Set log verbosity: `debug`, `info`, `warning`, `error` |
| `--generate-config` | | none | — | Write default config.json and config.README to blockchain directory, then exit |

## Precedence

```
CLI flags > config.json > built-in defaults
```

## Exit Codes

| Code | Meaning |
|------|---------|
| 0 | Success (normal exit, or `--help`/`--version`/`--generate-config` completed) |
| 1 | Error (invalid arguments, config validation failure, missing directory, file conflict) |

## Version Output Format

```
blockchain <version>
```

Where `<version>` is the `PACKAGE_VERSION` from `configure.ac` (e.g., `0.0.1`).

## Help Output Format

Structured output generated by Boost.ProgramOptions listing all options with descriptions and defaults. Example:

```
Usage: blockchain [OPTIONS] <blockchain-directory>

Options:
  -h, --help                 Show this help message
  -v, --version              Show version information
  --config <path>            Path to configuration file
  --rpc-port <port>          RPC listen port (default: 12345)
  --p2p-port <port>          P2P listen port (default: 12346)
  --seed-node <host:port>    Add seed node (repeatable)
  --log-level <level>        Log level: debug|info|warning|error (default: info)
  --generate-config          Generate default config.json and exit
```

## Error Output Format

Validation errors are written to stderr, one per line, prefixed with `Error:`:

```
Error: network.rpc_port: value 99999 out of valid range 1-65535
Error: network.rpc_port and network.p2p_port must not be equal (both are 12345)
Error: tls.cert_file: file not found: /path/to/cert.pem
```
